# AnimDraw

Покадровая анимация в браузере телефона (интерфейс по мотивам MediBang Paint, таймлайн по слоям).
Без сборки и зависимостей: чистые HTML/CSS/JS.

## Запуск
- Локально: открыть `index.html` в браузере.
- На телефоне через GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`, затем открыть выданную ссылку и добавить на главный экран.

## Что есть
- Кисть, ластик (размер в px, непрозрачность, жёсткость), заливка с порогом, закрытием пробелов и расширением
- Много слоёв: непрозрачность, режимы смешивания, защита альфы, обрезка, видимость
- Таймлайн по слоям: у каждого слоя своё число кадров (поле «Кадров слоя»), кадры слоя копируются, вставляются, дублируются, удаляются и двигаются; слой с меньшим числом кадров при проигрывании повторяется
- Калька, проигрывание с FPS, трансформация слоя (двигать/масштаб/поворот двумя пальцами), вращение и зум холста
- Журнал отмены с переходом на любой шаг, undo/redo
- Проекты: автосохранение в IndexedDB, список проектов, сохранение/открытие проекта файлом `.json`, экспорт PNG кадра

## Структура
- `index.html` — разметка
- `css/style.css` — стили
- `js/app.js` — вся логика (модель: `LS` — слои, у слоя `c[]` — кадры)

## Формат проекта (.json)
`{id, name, fps, n, updated, ls:[{n, v, o, bm, al, cl, c:[dataURL PNG, ...]}]}`
Старые проекты с общим списком кадров (`frames`) открываются и конвертируются.

## Планы
Выделение (лассо) и трансформация выделенного, пипетка, HSV-палитра, привязки и линейки,
GIF/MP4 экспорт, стабилизатор кисти, перетаскивание кадров жестом.
